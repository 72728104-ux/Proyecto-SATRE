# Plan de Pruebas Automatizadas e Incrementales por Archivos

Este directorio contiene las instrucciones paso a paso para que el agente de Cursor valide la integración entre Laravel, FastAPI y React.

## Instrucciones de Ejecución
Ejecuta las tareas en orden secuencial leyendo un archivo a la vez:
1. `01_iteracion_middleware_fix.md` (Corrección de middleware / Swagger)
2. `02_iteracion_endpoints_core.md` (Validación de API endpoints en FastAPI)
3. `03_iteracion_frontend_integration.md` (Ajuste de URLs y headers en el Frontend)
4. `04_iteracion_ia_agents.md` (Integración y prueba de agentes de IA conversacionales)
